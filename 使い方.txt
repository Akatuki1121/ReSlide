ReSlide の使い方
================

ReSlide は、PowerPoint（.pptx）の文字サイズと配置を整えるツールです。
元のファイルは上書きせず、整えた新しいファイルを返します。

使い方
------
1. ReSlide.bat に、整えたい .pptx ファイルをドラッグ＆ドロップします。
2. ウィンドウが開き、構成の指摘（見出しの繰り返し、折り返しの最後の行に
   数文字だけ残る形、並んだ要素の色の不揃い、長い注釈）が一覧で表示されます。
3. 直したい指摘にチェックを付けて、「選択した指摘を修正して保存」を
   押します。「文字の大きさや配置の自動調整も一緒に行う」にチェックが
   入っていると、文字サイズと配置の調整もあわせて行います。
   長い注釈は自動では直せないため、チェックは付けられません。
4. 元のファイル名に「_reslide」を付けた新しいファイルが、元のファイルと
   同じ場所にできます。あわせて、何をどう直したかの一覧（_changes.md）も
   出ます。

更新のお知らせ
--------------
起動時に、新しいバージョンが出ていないかを確認します。
新しいバージョンがあると、ウィンドウの上部に帯が出ます。
- 「ダウンロード」を押すと、新しい版の zip を保存します。終わったら
  ボタンが「保存先フォルダを開く」に変わるので、zip を展開して、
  ReSlide フォルダと ReSlide.bat を、今使っているものと差し替えて
  ください。
- 「後で」を押すと帯は消えます。手で確認したい時は、ウィンドウの
  「更新を確認」ボタンからも確認できます。

入っているもの
--------------
- ReSlide フォルダ   本体一式（この中にある ReSlide.exe が本体です）
- ReSlide.bat        ドラッグ＆ドロップ用の起動ファイル
- reslide_config.json 判定の基準値の設定（本文の下限など）

注意
----
- exe は無署名です。Windows の SmartScreen で警告が出た時は、
  「詳細情報」を選んでから「実行」を押してください。
- PowerPoint 本体は不要です。
- 判定だけしたい時や、ページ分割・並び替えの候補を見たい時、
  構成の指摘を番号で選んで直したい時は、コマンドラインから
  ReSlide フォルダの中の ReSlide.exe を直接実行できます。
  使い方は GitHub の README を見てください。
  https://github.com/Akatuki1121/ReSlide
