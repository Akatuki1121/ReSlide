# ReSlide

既存のPowerPointスライドを読み取り、文字のサイズや配置を実際に調整して見やすく整えるツールです。ときにはページの追加や分割、並び替えも行います。

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/sousei_1121)

- 対象: まずWindowsで作り、いずれMacにも対応する予定。短い企画発表やプレゼンで映すスライド
- 入力: 自分で作った既存の .pptx ファイル
- 判定の基準: 作者自身の過去のスライド作りの経験と、実際に発表資料へ受けた指摘をもとに決めています

## すること

- 余白が余っているのに小さい文字は、余白の範囲で大きくする（表のセル、図の中のラベル、フッターの注記など）
- 文字と図や線の重なり、枠からのはみ出しは、配置を動かして解消する
- 折り返しで見出しと本文が重なる場合は、サイズと配置を調整する
- 近くにある要素同士の位置のずれを揃える
- 1枚に詰め込みすぎているページは、分割してページを増やす
- 流れに合わないページの順番は並び替える
- 文字を大きくする代わりに、本文を短く切ることもある

調整した結果を、新しい .pptx として返します。

## 基準値のメモ（自分の経験から）

原ゼミの企画発表スライドを作った時の実感と指摘から置いた暫定値です。作りながら調整します。

- 本文18pt・図ラベル14ptでは小さすぎた
- 本文は24pt以上が目安。最終的には26〜33ptくらいが読みやすかった
- タイトルは大きく取り、見出しと本文にもはっきり差をつける
- 文字を大きくする代わりに、本文を短く切ることも直し方に入る

## 入手と使い方

Releases から zip をダウンロードして、中の ReSlide.bat に .pptx ファイルをドラッグ＆ドロップすると、調整した新しいファイルができます。詳しくは zip に同梱の「使い方.txt」を見てください。
